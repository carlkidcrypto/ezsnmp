EzSnmp Documentation
====================

.. image:: ../../../images/ezsnmp_logo.jpeg
   :alt: EzSnmp Logo
   :align: center
   :width: 300px

**EzSnmp** is a blazing-fast, Pythonic SNMP client library that wraps the official
`Net-SNMP <http://www.net-snmp.org/>`_ library using a C++ extension. It provides
high-throughput, low-latency SNMP polling and telemetry across large fleets of network devices.

Key Features
------------

* **Speed & Concurrency:** High-performance C++ core that releases Python's GIL during network queries.
* **Protocol Support:** Full support for SNMPv1, SNMPv2c, and SNMPv3 (MD5/SHA auth, DES/AES encryption).
* **Comprehensive Operations:** Pythonic APIs for ``get``, ``set``, ``walk``, ``bulkwalk``, and ``bulkget``.
* **Cross-Platform:** Available for Linux, macOS, and Windows.
